# Game of LiveView

A random experiment to implement [Conway’s Game of
Life](https://en.wikipedia.org/wiki/Conway's_Game_of_Life) on a canvas in a
LiveView, with each living cell modelled by its own process (this would almost
certainly be a terrible idea for a real application).

To start your Phoenix server:

* Run `mix setup` to install and setup dependencies
* Start Phoenix endpoint with `mix phx.server` or inside IEx with `iex -S mix phx.server`

Now you can visit [`localhost:4000`](http://localhost:4000) from your browser.
